# Loomline documentation

Start with a running platform and one real shared memory, then connect your own
agents. Every guide uses the same FalkorDB-backed engine and authenticated API.

| [MCP tools](mcp-tools.md) | Inspect all 27 tools, input limits, retry identities and error semantics. |
| [Frameworks & NVIDIA](integrations.md) | Run native LangChain, LangGraph, CrewAI and custom Python workflows. |
| [Graph model](graph-model.md) | Review the actual labels, relationships, Cypher and consistency boundaries. |
| [Memory contract](memory-contract.md) | Check memory lifecycles, authorization, idempotency and continuity rules. |
| [Verification](verification.md) | Review executed checks, reproduce tests and understand remaining limits. |
